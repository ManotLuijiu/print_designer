# Print Designer engineering harness

This harness mirrors the established `thai_business_suite/harness` layout.

- `agents/` — role definitions for planning, Frappe, JavaScript, testing, and verification
- `checklists/` — safety and release verification gates
- `logs/` — command, execution, and agent continuity logs
- `plans/` — resumable Markdown and machine-readable task plans
- `playbooks/` — reusable Frappe workflows
- `reports/` — investigation and implementation evidence
- `schemas/` — plan schemas
