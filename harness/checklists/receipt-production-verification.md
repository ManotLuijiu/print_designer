# Receipt production verification checklist

- [ ] Initial `.main-container` count is at least 1 before interaction.
- [ ] Saved Receipt header, body, and footer are visible.
- [ ] No relevant console errors or failed requests.
- [ ] Add Page renders a new page without saving during the smoke test.
- [ ] Marquee selection works on empty space and elements.
- [ ] PDF preview renders.
- [ ] Exit and re-entry work without leaked mounts/listeners.
- [ ] Navbar inline styles restore exactly after exit.
- [ ] Beta badge is absent.
- [ ] Saved Receipt payload remains unchanged unless the user intentionally saves.
